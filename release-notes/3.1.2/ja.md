# BIOPlayer 3.1.2

# 推奨アップデート

- 生理曲線の可視化
- 楽曲名の表示設定を追加しました。表示する項目（タイトル、アーティスト、アルバム、ファイル名、拡張子）を選択し、順序を変更できます。
- PDF内の楽曲名に個別の表示設定を追加しました。
- 検索条件に「アルバム」を追加しました。
- セッションの読み込み時に見つからない楽曲が4曲以上ある場合、セッション全体の不足している楽曲を検索できます。
- 翻訳を改善しました。
- 重要：アカウントへのアクセスが一時的にブロックされることがあった不具合を修正しました。
- 別の場所で楽曲をトリミングまたは削除した場合や、エクササイズを削除した場合に、現在のエクササイズまで意図せずスクロールする不具合を修正しました。
