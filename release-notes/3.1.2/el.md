# BIOPlayer 3.1.2

# ΣΥΝΙΣΤΩΜΕΝΗ ΕΝΗΜΕΡΩΣΗ

- Οπτικοποίηση της φυσιολογικής καμπύλης
- Προσθήκη ρύθμισης ονομασίας μουσικών κομματιών: επιλογή των πεδίων που εμφανίζονται (τίτλος, καλλιτέχνης, άλμπουμ, όνομα αρχείου, επέκταση) και προσαρμόσιμη σειρά.
- Προσθήκη ανεξάρτητης ρύθμισης ονομασίας μουσικών κομματιών στα PDF.
- Προσθήκη του κριτηρίου «Άλμπουμ» στα κριτήρια αναζήτησης.
- Δυνατότητα αναζήτησης των μουσικών κομματιών που λείπουν σε ολόκληρη τη συνεδρία, όταν δεν βρίσκονται περισσότερα από τρία κομμάτια κατά τη φόρτωσή της.
- Βελτίωση των μεταφράσεων.
- ΣΗΜΑΝΤΙΚΟ: διόρθωση σφάλματος που μπορούσε να εμποδίσει προσωρινά την πρόσβαση στον λογαριασμό σας.
- Διόρθωση της ανεπιθύμητης κύλισης στην τρέχουσα άσκηση όταν ένα μουσικό κομμάτι περικόπτεται ή διαγράφεται σε άλλο σημείο ή όταν διαγράφεται μια άσκηση.
