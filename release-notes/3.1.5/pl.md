# BIOPlayer 3.1.5

- Nowy układ ustawień.
- Możliwość drukowania krzywej fizjologicznej lub eksportowania jej do PDF (podziękowania dla Laurent P.).
- Trzy tryby rozwijania i zwijania ćwiczeń, w tym nowy tryb „z wybraną muzyką + tymi samymi utworami” (podziękowania dla Zoë R.).
- Możliwość edycji treści instrukcji i nazw ćwiczeń nawet bez aktywnej licencji (podziękowania dla Pegyy S.).
- Import całej biblioteki iTunes.
- Obsługa otwierania plików .toro w trybie tylko do odczytu.
- Usunięto pozycje menu dotyczące szczytów, tylko w środkowym obszarze.
- Poprawki błędów:
    - W niektórych rzadkich przypadkach przejścia uruchamiała się muzyka następnego ćwiczenia zamiast muzyki bieżącego ćwiczenia.
    - Duplikowanie ćwiczenia lub kopiowanie go z zewnątrz nie zachowywało szczytu aktywacji.
- Dymki informacyjne o muzyce w obszarze wyszukiwania są wyłączone, gdy otwarte jest menu w lewym górnym rogu.
- Zmieniono komunikat o ponownym uruchomieniu po instalacji w systemie Linux.
- W systemie Windows automatyczna aktualizacja instaluje teraz nową wersję w trybie cichym, a następnie automatycznie uruchamia BIOPlayer ponownie po zapisaniu sesji.
- Kilka ulepszeń interfejsu użytkownika.
