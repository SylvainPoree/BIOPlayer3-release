# BIOPlayer 3.1.5

- New layout for the options.
- You can now print the physiological curve or export it as a PDF (thanks to Laurent P.).
- Three modes for expanding or collapsing exercises, including the new “with the selected music + same music” mode (thanks to Zoë R.).
- You can edit instruction content and exercise names even without an active licence (thanks to Pegyy S.).
- Import an entire iTunes library.
- Support for opening .toro files in read-only mode.
- Removed menu items relating to peaks from the central area only.
- Bug fixes:
    - In some rare transition scenarios, the music for the next exercise would start instead of the music for the current exercise.
    - Duplicating an exercise or copying it from outside would not preserve its activation peak.
- Music information bubbles in the search area are disabled while the top-left menu is open.
- Updated the message about restarting after installation on Linux.
- On Windows, automatic updates now install the new version silently, then restart BIOPlayer automatically after saving sessions.
- Several user interface improvements.
