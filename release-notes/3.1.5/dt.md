# BIOPlayer 3.1.5

- Neue Darstellung der Einstellungen.
- Die physiologische Kurve kann gedruckt oder als PDF exportiert werden (danke an Laurent P.).
- Drei Modi zum Auf- und Zuklappen der Übungen, darunter der neue Modus „mit der ausgewählten Musik + denselben Musikstücken“ (danke an Zoë R.).
- Inhalte der Anleitungen und Namen der Übungen können auch ohne aktive Lizenz bearbeitet werden (danke an Pegyy S.).
- Import einer vollständigen iTunes-Mediathek.
- Unterstützung für das Öffnen von .toro-Dateien im schreibgeschützten Modus.
- Menüpunkte zu den Spitzen entfernt, ausschließlich im mittleren Bereich.
- Fehlerbehebungen:
    - In einigen seltenen Übergangssituationen startete die Musik der nächsten Übung anstelle der Musik der aktuellen Übung.
    - Beim Duplizieren einer Übung oder beim Kopieren von außerhalb wurde die Aktivierungsspitze nicht übernommen.
- Die Musik-Infoblasen im Suchbereich sind deaktiviert, solange das Menü oben links geöffnet ist.
- Die Meldung zum Neustart nach der Installation unter Linux geändert.
- Unter Windows installiert die automatische Aktualisierung die neue Version jetzt im Hintergrund und startet BIOPlayer anschließend nach dem Speichern der Sitzungen automatisch neu.
- Einige Verbesserungen der Benutzeroberfläche.
