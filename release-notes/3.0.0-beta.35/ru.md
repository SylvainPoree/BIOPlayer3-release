# Основные изменения

- UI: Улучшено обозначение воспроизводимой музыки (музыкальная нота) в сеансе и в результатах поиска.
- UI: Улучшен внешний вид контроллера.
- UI: Удален оставшийся код качающегося индикатора загрузки на экране Fusion.
- DEBUG: Исправлены невидимые области, которые могли перехватывать клики на начальном экране: теперь можно нажимать на флаги и кнопки, даже когда поверх них находятся Kiki или -BIOPlayer-.
- ФУНКЦИЯ: Улучшено восстановление идентификатора: отсутствующий лицензионный ключ создается автоматически, если учетная запись все еще использовала временное значение `000-000-000`.
- TECH: Улучшена публикация заметок об обновлении на GitHub Pages без зависимости от `rsync`.
- TECH: Установщики Windows разделены по каналам: `BIOPlayer`, `BIOPlayer Beta` и `BIOPlayer Dev` теперь могут сосуществовать на одном компьютере.
- UI: Исправлено поле издателя Windows: оно остается `BIOPlayer` для всех каналов.
