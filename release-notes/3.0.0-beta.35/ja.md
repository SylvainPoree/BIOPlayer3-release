# 主な変更点

- UI: セッション内および検索結果内で、再生中の音楽（音符）の表示を改善しました。
- UI: コントローラーの見た目を改善しました。
- UI: Fusion画面に残っていた揺れる読み込みボールのコードを削除しました。
- DEBUG: ホーム画面でクリックを妨げることがあった見えない領域を修正しました。Kikiや-BIOPlayer-が重なっていても、旗やボタンをクリックできるようになりました。
- 機能: 識別子の復旧を改善しました。アカウントが一時値 `000-000-000` をまだ使用している場合、不足しているライセンスキーが自動生成されます。
- TECH: `rsync` に依存せずに GitHub Pages のリリースノートを公開できるよう改善しました。
- TECH: Windowsインストーラーをチャンネル別に分離しました。`BIOPlayer`、`BIOPlayer Beta`、`BIOPlayer Dev` を同じPC上で共存できるようになりました。
- UI: Windowsの発行元フィールドを修正しました。すべてのチャンネルで `BIOPlayer` のままになります。
