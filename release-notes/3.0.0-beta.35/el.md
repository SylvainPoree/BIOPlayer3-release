# Κύριες αλλαγές

- UI: Βελτιωμένη αναγνώριση της μουσικής που αναπαράγεται (μουσική νότα) στη συνεδρία και στα αποτελέσματα αναζήτησης.
- UI: Βελτιώθηκε η οπτική εμφάνιση του χειριστηρίου.
- UI: Αφαιρέθηκε ο υπόλοιπος κώδικας της ταλαντευόμενης μπάλας φόρτωσης από την οθόνη Fusion.
- DEBUG: Διορθώθηκαν αόρατες περιοχές που μπορούσαν να παρεμποδίσουν κλικ στην αρχική οθόνη: οι σημαίες και τα κουμπιά μπορούν πλέον να πατηθούν ακόμη και όταν το Kiki ή το -BIOPlayer- βρίσκονται από πάνω τους.
- ΛΕΙΤΟΥΡΓΙΑ: Βελτιώθηκε η ανάκτηση αναγνωριστικού: ένα κλειδί άδειας που λείπει δημιουργείται αυτόματα αν ο λογαριασμός εξακολουθούσε να χρησιμοποιεί την προσωρινή τιμή `000-000-000`.
- TECH: Βελτιώθηκε η δημοσίευση των σημειώσεων ενημέρωσης στο GitHub Pages, χωρίς εξάρτηση από το `rsync`.
- TECH: Διαχωρίστηκαν οι εγκαταστάτες Windows ανά κανάλι: `BIOPlayer`, `BIOPlayer Beta` και `BIOPlayer Dev` μπορούν πλέον να συνυπάρχουν στον ίδιο υπολογιστή.
- UI: Διορθώθηκε το πεδίο εκδότη στα Windows: παραμένει `BIOPlayer` για όλα τα κανάλια.
