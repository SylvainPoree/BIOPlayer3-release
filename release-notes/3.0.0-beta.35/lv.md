# Galvenās izmaiņas

- UI: Uzlabota pašlaik atskaņotās mūzikas atzīmēšana (mūzikas nots) sesijā un meklēšanas rezultātos.
- UI: Uzlabots kontroliera vizuālais izskats.
- UI: No Fusion ekrāna noņemts atlikušais svārstīgās ielādes bumbas kods.
- DEBUG: Labotas neredzamas zonas, kas varēja pārtvert klikšķus sākuma ekrānā: uz karodziņiem un pogām tagad var noklikšķināt arī tad, ja virs tiem atrodas Kiki vai -BIOPlayer-.
- FUNKCIJA: Uzlabota identifikatora atgūšana: trūkstoša licences atslēga tiek ģenerēta automātiski, ja konts joprojām izmantoja pagaidu vērtību `000-000-000`.
- TECH: Uzlabota atjauninājumu piezīmju publicēšana GitHub Pages, bez atkarības no `rsync`.
- TECH: Windows instalatori ir atdalīti pēc kanāla: `BIOPlayer`, `BIOPlayer Beta` un `BIOPlayer Dev` tagad var pastāvēt līdzās vienā datorā.
- UI: Labots Windows izdevēja lauks: tas visiem kanāliem paliek `BIOPlayer`.
