# Glavne spremembe

- UI: Izboljšano označevanje trenutno predvajane glasbe (glasbena nota) v seji in v rezultatih iskanja.
- UI: Izboljšan vizualni videz krmilnika.
- UI: Odstranjena preostala koda nihajoče nalagalne kroglice z zaslona Fusion.
- DEBUG: Popravljena nevidna območja, ki so lahko prestrezala klike na začetnem zaslonu: zastavice in gumbe je zdaj mogoče klikniti tudi, ko sta Kiki ali -BIOPlayer- nad njimi.
- FUNKCIJA: Izboljšana obnovitev identifikatorja: manjkajoči licenčni ključ se samodejno ustvari, če je račun še vedno uporabljal začasno vrednost `000-000-000`.
- TECH: Izboljšana objava opomb ob posodobitvah na GitHub Pages, brez odvisnosti od `rsync`.
- TECH: Namestitveni programi za Windows so ločeni po kanalih: `BIOPlayer`, `BIOPlayer Beta` in `BIOPlayer Dev` lahko zdaj sobivajo na istem računalniku.
- UI: Popravljeno polje izdajatelja v sistemu Windows: za vse kanale ostane `BIOPlayer`.
