# Viktigste endringer

- UI: Forbedret markering av musikken som spilles av (musikknote) i økten og i søkeresultatene.
- UI: Forbedret det visuelle utseendet til kontrolleren.
- UI: Fjernet gjenværende kode for den oscillerende lasteballen fra Fusion-skjermen.
- DEBUG: Rettet usynlige områder som kunne fange klikk på startsiden: flagg og knapper kan nå klikkes selv når Kiki eller -BIOPlayer- ligger over dem.
- FUNKSJON: Forbedret gjenoppretting av identifikator: en manglende lisensnøkkel genereres automatisk hvis kontoen fortsatt brukte den midlertidige verdien `000-000-000`.
- TECH: Forbedret publisering av versjonsnotater på GitHub Pages, uten avhengighet av `rsync`.
- TECH: Windows-installasjonsprogrammer er skilt per kanal: `BIOPlayer`, `BIOPlayer Beta` og `BIOPlayer Dev` kan nå eksistere side om side på samme datamaskin.
- UI: Rettet Windows-feltet for utgiver: det forblir `BIOPlayer` for alle kanaler.
