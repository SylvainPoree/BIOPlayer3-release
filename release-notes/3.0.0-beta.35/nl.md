# Belangrijkste wijzigingen

- UI: Verbeterde herkenning van de muziek die wordt afgespeeld (muzieknoot) in de sessie en in zoekresultaten.
- UI: Verbeterde visuele weergave van de controller.
- UI: Resterende code van de oscillerende laadbal verwijderd uit het Fusion-scherm.
- DEBUG: Onzichtbare zones gecorrigeerd die klikken op het startscherm konden onderscheppen: vlaggen en knoppen kunnen nu worden aangeklikt, ook wanneer Kiki of -BIOPlayer- erboven staan.
- FUNCTIE: Verbeterd herstel van de identifier: een ontbrekende licentiesleutel wordt automatisch gegenereerd als het account nog de tijdelijke waarde `000-000-000` gebruikte.
- TECH: Verbeterde publicatie van release notes op GitHub Pages, zonder afhankelijkheid van `rsync`.
- TECH: Windows-installers gescheiden per kanaal: `BIOPlayer`, `BIOPlayer Beta` en `BIOPlayer Dev` kunnen nu naast elkaar op dezelfde computer staan.
- UI: Het Windows-uitgeversveld gecorrigeerd: dit blijft `BIOPlayer` voor alle kanalen.
