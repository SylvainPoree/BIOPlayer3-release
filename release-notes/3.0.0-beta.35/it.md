# Cambiamenti principali

- UI: Migliorata l'identificazione della musica in riproduzione (nota musicale) nella sessione e nei risultati di ricerca.
- UI: Migliorato l'aspetto visivo del controller.
- UI: Rimosso il codice residuo della pallina di caricamento oscillante nella schermata Fusion.
- DEBUG: Corrette aree invisibili che potevano intercettare i clic nella schermata iniziale: ora è possibile cliccare sulle bandiere e sui pulsanti anche quando Kiki o -BIOPlayer- sono sopra di essi.
- FUNZIONE: Migliorato il recupero dell'identificativo: una chiave di licenza mancante viene generata automaticamente se l'account usava ancora il valore temporaneo `000-000-000`.
- TECH: Migliorata la pubblicazione delle note di aggiornamento su GitHub Pages, senza dipendenza da `rsync`.
- TECH: Separazione degli installer Windows per canale: `BIOPlayer`, `BIOPlayer Beta` e `BIOPlayer Dev` possono ora coesistere sullo stesso computer.
- UI: Corretto il campo editore di Windows: rimane `BIOPlayer` per tutti i canali.
