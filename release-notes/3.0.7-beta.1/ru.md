# BIOPlayer 3.0.7-beta.1
- Добавлена папка по умолчанию для сеансов и музыки
- Добавлена возможность изменять псевдоним
- При создании учетной записи добавлены номер телефона и статус преподаватель/не преподаватель
- Добавлено получение данных во время оплаты, особенно email, используемого как идентификатор в BIOPlayer, с предупреждением при необходимости
- Усилена возможность одновременно иметь установленными бета-версию и стабильную версию
