# BIOPlayer 3.1.4

- Added copy and paste for exercises and music tracks.
- Revised context menus.
- Added a setting to open sessions in a second window.
- You can cross the trimming handles to remove a middle section of a music track.
- You can enable automatic rhythm synchronization for a hard cut, a loop or transitions within the same track.
- Use Ctrl + mouse wheel to zoom the entire interface in or out.
- Added new features to the physiological curve and the option to include it in PDFs.
- Revised option labels and layout.
- Installation and updates on Mac using a signed installer.
- Various display improvements:
    - Instant spectrum display, from left to right.
    - Kiki takes to the decks when no music is loaded.
    - Consistent dialog boxes.
    - Improved physiological curve.
    - Other adjustments.
