# BIOPlayer 3.1.4

- Adicionadas as funções de copiar e colar para exercícios e músicas.
- Revistos os menus de contexto.
- Adicionada uma definição para abrir sessões numa segunda janela.
- É possível cruzar as pegas de corte para remover uma parte central de uma música.
- É possível ativar a sincronização rítmica automática num corte seco, num ciclo ou em transições dentro da mesma música.
- Pode usar Ctrl + roda do rato para ampliar ou reduzir toda a interface.
- Adicionadas novas funcionalidades à curva fisiológica e a possibilidade de a incluir nos PDF.
- Revistos os textos e a apresentação das definições.
- Instalação e atualizações no Mac com um instalador assinado.
- Várias melhorias de visualização:
    - Visualização instantânea do espectro, da esquerda para a direita.
    - Kiki assume os pratos quando não há música carregada.
    - Uniformização das caixas de diálogo.
    - Melhoria da curva fisiológica.
    - Outros ajustes.
