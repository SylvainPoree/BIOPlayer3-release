# BIOPlayer 3.1.4

- Προστέθηκε αντιγραφή και επικόλληση για ασκήσεις και μουσικά κομμάτια.
- Αναθεωρήθηκαν τα μενού περιβάλλοντος.
- Προστέθηκε ρύθμιση για το άνοιγμα συνεδριών σε δεύτερο παράθυρο.
- Μπορείτε να διασταυρώσετε τις λαβές περικοπής για να αφαιρέσετε ένα μεσαίο τμήμα ενός μουσικού κομματιού.
- Μπορείτε να ενεργοποιήσετε τον αυτόματο ρυθμικό συγχρονισμό σε απότομη τομή, βρόχο ή μεταβάσεις μέσα στο ίδιο κομμάτι.
- Χρησιμοποιήστε Ctrl + ροδέλα ποντικιού για μεγέθυνση ή σμίκρυνση ολόκληρης της διεπαφής.
- Προστέθηκαν νέες λειτουργίες στη φυσιολογική καμπύλη και η δυνατότητα συμπερίληψής της στα PDF.
- Αναθεωρήθηκαν οι ετικέτες και η παρουσίαση των ρυθμίσεων.
- Εγκατάσταση και ενημερώσεις σε Mac με υπογεγραμμένο πρόγραμμα εγκατάστασης.
- Διάφορες βελτιώσεις εμφάνισης:
    - Άμεση εμφάνιση του φάσματος από αριστερά προς τα δεξιά.
    - Ο Kiki αναλαμβάνει τα πικάπ όταν δεν έχει φορτωθεί μουσική.
    - Ενοποίηση των πλαισίων διαλόγου.
    - Βελτίωση της φυσιολογικής καμπύλης.
    - Άλλες προσαρμογές.
