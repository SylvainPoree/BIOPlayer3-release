# BIOPlayer 3.1.4

- Pievienota vingrinājumu un mūzikas ierakstu kopēšana un ielīmēšana.
- Pārskatītas kontekstizvēlnes.
- Pievienots iestatījums sesiju atvēršanai otrā logā.
- Apgriešanas rokturus var krustot, lai noņemtu mūzikas ieraksta vidusdaļu.
- Var aktivizēt automātisko ritma sinhronizāciju asam griezumam, ciklam vai pārejām viena skaņdarba ietvaros.
- Ar Ctrl + peles ritenīti var palielināt vai samazināt visu saskarni.
- Fizioloģiskajai līknei pievienotas jaunas funkcijas un iespēja to iekļaut PDF failos.
- Pārskatīti iestatījumu nosaukumi un izkārtojums.
- Instalēšana un atjaunināšana Mac datoros ar parakstītu instalēšanas programmu.
- Dažādi attēlojuma uzlabojumi:
    - Tūlītējs spektra attēlojums no kreisās uz labo pusi.
    - Kiki stājas pie dīdžeja pults, kad nav ielādēta mūzika.
    - Vienādoti dialoglodziņi.
    - Uzlabota fizioloģiskā līkne.
    - Citi pielāgojumi.
