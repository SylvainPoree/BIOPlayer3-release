# BIOPlayer 3.1.4

- Lagt till kopiering och inklistring av övningar och musikspår.
- Omarbetade snabbmenyer.
- Lagt till en inställning för att öppna sessioner i ett andra fönster.
- Klipphandtagen kan korsas för att ta bort en mittdel av ett musikspår.
- Automatisk rytmsynkronisering kan aktiveras vid ett hårt klipp, en loop eller övergångar inom samma musikstycke.
- Använd Ctrl + mushjul för att förstora eller förminska hela gränssnittet.
- Lagt till nya funktioner för den fysiologiska kurvan och möjligheten att inkludera den i PDF-filer.
- Omarbetat texterna och utformningen av inställningarna.
- Installation och uppdateringar på Mac med ett signerat installationsprogram.
- Olika visningsförbättringar:
    - Omedelbar visning av spektrumet, från vänster till höger.
    - Kiki tar plats bakom skivspelarna när ingen musik är inläst.
    - Enhetliga dialogrutor.
    - Förbättrad fysiologisk kurva.
    - Andra justeringar.
