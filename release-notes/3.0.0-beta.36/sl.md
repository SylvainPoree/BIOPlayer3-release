# Glavne spremembe

- UI: Dodan in usklajen svetlobni sij / utripanje na notah, ko se predvaja glasba.
- UI: Krepki prikaz, ko se glasba predvaja.
- UI: Spremenjeno besedilo pomoči pri iskanju, ki je zdaj odvisno od dejanskih največjih omejitev glede na to, ali je licenca aktivirana ali ne.
- UI: Upravljanje povečave ob inicializaciji.
- UI: Povečava ob premiku miške čez vaje, ikone svinčnika in druge kontrolnike.
- DEBUG: Popravljen zamik predvajanega rezultata iskanja pri ponavljajočih se pritiskih na Enter.
- FUNKCIJA: Brez aktivne licence interakcije ostanejo na voljo in spremeni se samo omejitev števila glasb na vajo.
- UI: Ni več vidnega BIOP / BIOPLayer / Bioplayer; prikazan je samo BIOPlayer.
- UI: V UI JSON datotekah ni več SMS-slogovnih emotikonov.
- UI: Odstranjena omejitev zamika z desne proti levi pri predvajani glasbi.
- FUNKCIJA: Način brez aktivne licence ponovno omejuje seje na 5 vaj.
- FUNKCIJA: Omejitev števila glasb na vajo je zdaj odvisna od licence.
- FUNKCIJA: Dodajanje, podvajanje, uvozi in drops vaj zdaj upoštevajo omejitev, povezano z licenco.
- FUNKCIJA: Sej, ki presegajo dovoljeno omejitev, ni več mogoče spreminjati ali shranjevati, dokler licenca ni aktivna.
- FUNKCIJA: Nova možnost: centriraj navodilo, ki se trenutno ureja.
- FUNKCIJA: Klik na ime predvajane glasbe poišče njen izvor: vaja ali iskanje.
- TECH: Beleženje postopka posodobitve.
- TECH: Spremenjena administrativna e-pošta ob ustvarjanju.
