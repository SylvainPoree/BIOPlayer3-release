# Основные изменения

- UI: Добавлен и унифицирован светящийся ореол / мигание на нотах, когда музыка воспроизводится.
- UI: Жирное отображение текущей воспроизводимой музыки.
- UI: Изменен текст справки поиска: теперь он зависит от реальных максимальных ограничений в зависимости от того, активирована ли лицензия.
- UI: Управление масштабом при инициализации.
- UI: Увеличение при наведении на упражнения, значки карандаша и другие элементы управления.
- DEBUG: Исправлено смещение воспроизводимого результата поиска при повторных нажатиях Enter.
- ФУНКЦИЯ: Без активной лицензии взаимодействия остаются доступными, меняется только ограничение числа музыкальных треков на упражнение.
- UI: Больше не остается видимого BIOP / BIOPLayer / Bioplayer; отображается только BIOPlayer.
- UI: В UI JSON больше нет SMS-эмотиконов.
- UI: Удалено ограничение смещения справа налево в воспроизводимой музыке.
- ФУНКЦИЯ: Режим без активной лицензии снова ограничивает сессии 5 упражнениями.
- ФУНКЦИЯ: Ограничение числа музыкальных треков на упражнение теперь зависит от лицензии.
- ФУНКЦИЯ: Добавление, дублирование, импорт и drops упражнений теперь учитывают ограничение, связанное с лицензией.
- ФУНКЦИЯ: Сессии, превышающие разрешенный лимит, больше нельзя изменять или сохранять, пока лицензия не активна.
- ФУНКЦИЯ: Новая опция: центрировать инструкцию, которая сейчас редактируется.
- ФУНКЦИЯ: Щелчок по названию воспроизводимой музыки находит ее источник: упражнение или поиск.
- TECH: Журналирование процедуры обновления.
- TECH: Изменено административное письмо, отправляемое при создании.
