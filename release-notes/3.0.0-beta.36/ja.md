# 主な変更点

- UI: 音楽の再生中に音符へ表示される発光ハロー / 点滅効果を追加し、統一しました。
- UI: 音楽の再生中は太字で表示するようにしました。
- UI: 検索ヘルプの文言を変更し、ライセンスが有効かどうかに応じて実際の最大値を反映するようにしました。
- UI: 初期化時のズーム管理を追加しました。
- UI: エクササイズ、鉛筆アイコン、その他のコントロールにホバー時のズームを追加しました。
- DEBUG: Enter を連続して押したときに、再生中の検索結果の位置がずれる問題を修正しました。
- 機能: 有効なライセンスがない場合でも操作は利用可能なままで、変更されるのはエクササイズごとの音楽数の上限のみです。
- UI: 表示上の BIOP / BIOPLayer / Bioplayer は残っておらず、BIOPlayer のみが表示されます。
- UI: UI JSON から SMS 風の顔文字をなくしました。
- UI: 再生中の音楽表示にあった右から左へのずれ制限を削除しました。
- 機能: 有効なライセンスがないモードでは、セッションが再び 5 エクササイズに制限されます。
- 機能: エクササイズごとの音楽数の上限は、ライセンスに応じて決まるようになりました。
- 機能: エクササイズの追加、複製、インポート、ドロップは、ライセンスに関連する上限を守るようになりました。
- 機能: 許可された上限を超えるセッションは、ライセンスが有効になるまで編集または保存できなくなりました。
- 機能: 新しいオプション: 編集中の指示を中央に配置。
- 機能: 再生中の音楽名をクリックすると、その音楽の元の場所を見つけられます: エクササイズまたは検索。
- TECH: 更新手順のログ記録。
- TECH: 作成時に送信される管理者メールを変更しました。
