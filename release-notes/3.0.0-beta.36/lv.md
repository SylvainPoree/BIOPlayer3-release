# Galvenās izmaiņas

- UI: Pievienots un saskaņots gaismas oreols / mirgošana uz notīm, kad tiek atskaņota mūzika.
- UI: Treknraksta attēlojums, kad tiek atskaņota mūzika.
- UI: Mainīts meklēšanas palīdzības teksts; tas tagad ir atkarīgs no reālajiem maksimālajiem ierobežojumiem atkarībā no tā, vai licence ir aktivizēta.
- UI: Tālummaiņas pārvaldība inicializācijas laikā.
- UI: Tālummaiņa, novietojot kursoru virs vingrinājumiem, zīmuļa ikonām un citām vadīklām.
- DEBUG: Izlabota atskaņotā meklēšanas rezultāta nobīde, atkārtoti spiežot Enter.
- FUNKCIJA: Bez aktīvas licences mijiedarbības paliek pieejamas, un mainās tikai mūziku skaita ierobežojums vienam vingrinājumam.
- UI: Vairs nav redzams BIOP / BIOPLayer / Bioplayer; tiek rādīts tikai BIOPlayer.
- UI: UI JSON failos vairs nav SMS stila emocijzīmju.
- UI: Noņemts labās-uz-kreiso nobīdes ierobežojums atskaņotajā mūzikā.
- FUNKCIJA: Režīms bez aktīvas licences atkal ierobežo sesijas līdz 5 vingrinājumiem.
- FUNKCIJA: Mūziku skaita ierobežojums vienam vingrinājumam tagad ir atkarīgs no licences.
- FUNKCIJA: Vingrinājumu pievienošana, dublēšana, imports un drops tagad ievēro ar licenci saistīto ierobežojumu.
- FUNKCIJA: Sesijas, kas pārsniedz atļauto ierobežojumu, vairs nevar mainīt vai saglabāt, kamēr licence nav aktīva.
- FUNKCIJA: Jauna opcija: centrēt pašlaik rediģēto instrukciju.
- FUNKCIJA: Klikšķis uz atskaņotās mūzikas nosaukuma atrod tās izcelsmi: vingrinājumu vai meklēšanu.
- TECH: Atjaunināšanas procedūras žurnalēšana.
- TECH: Mainīts administratora e-pasts, kas tiek nosūtīts izveides laikā.
