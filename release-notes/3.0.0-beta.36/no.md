# Viktigste endringer

- UI: Lysglo / blinking på notene når musikk spilles av er lagt til og harmonisert.
- UI: Fet visning når musikk spilles av.
- UI: Hjelpeteksten for søk er endret og avhenger nå av de reelle maksimumsgrensene etter om lisensen er aktivert eller ikke.
- UI: Zoom håndteres ved initialisering.
- UI: Zoom ved hover over øvelser, blyantikoner og andre kontroller.
- DEBUG: Rettet forskyvningen av søkeresultatet som spilles av ved gjentatte trykk på Enter.
- FUNKSJON: Uten aktiv lisens er interaksjonene fortsatt tilgjengelige, og bare grensen for antall musikkspor per øvelse endres.
- UI: Ingen synlige BIOP / BIOPLayer / Bioplayer gjenstår; bare BIOPlayer vises.
- UI: Ingen SMS-lignende emotikoner i UI-JSON-filene.
- UI: Fjernet begrensningen for høyre-til-venstre-forskyvning i musikken som spilles av.
- FUNKSJON: Modusen uten aktiv lisens begrenser igjen økter til 5 øvelser.
- FUNKSJON: Grensen for antall musikkspor per øvelse avhenger nå av lisensen.
- FUNKSJON: Tillegg, duplisering, import og dropping av øvelser respekterer nå grensen knyttet til lisensen.
- FUNKSJON: Økter som overstiger den tillatte grensen kan ikke lenger endres eller lagres så lenge lisensen ikke er aktiv.
- FUNKSJON: Nytt alternativ: sentrer instruksjonen som redigeres.
- FUNKSJON: Et klikk på navnet til musikken som spilles av finner opprinnelsen: øvelse eller søk.
- TECH: Logging av oppdateringsprosedyren.
- TECH: Admin-e-post ved opprettelse er endret.
