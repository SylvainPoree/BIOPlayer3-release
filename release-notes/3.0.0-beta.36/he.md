# שינויים עיקריים

- UI: נוסף ואוחד הילה זוהרת / הבהוב על התווים כאשר מוזיקה מתנגנת.
- UI: תצוגה מודגשת כאשר מוזיקה מתנגנת.
- UI: טקסט העזרה של החיפוש עודכן, וכעת הוא תלוי במגבלות המקסימום האמיתיות לפי מצב הפעלת הרישיון.
- UI: ניהול זום בעת האתחול.
- UI: זום בריחוף מעל תרגילים, סמלי עיפרון ובקרות אחרות.
- DEBUG: תוקנה הסטייה של תוצאת החיפוש המתנגנת בעת לחיצות חוזרות על Enter.
- תכונה: ללא רישיון פעיל, האינטראקציות נשארות זמינות ורק מגבלת מספר קטעי המוזיקה לכל תרגיל משתנה.
- UI: לא נשאר BIOP / BIOPLayer / Bioplayer גלוי; מוצג רק BIOPlayer.
- UI: אין יותר אמוטיקונים בסגנון SMS בקובצי UI JSON.
- UI: הוסרה מגבלת ההסטה מימין לשמאל במוזיקה המתנגנת.
- תכונה: מצב ללא רישיון פעיל שוב מגביל מפגשים ל-5 תרגילים.
- תכונה: מגבלת מספר קטעי המוזיקה לכל תרגיל תלויה כעת ברישיון.
- תכונה: הוספה, שכפול, ייבוא ו-drops של תרגילים מכבדים כעת את המגבלה הקשורה לרישיון.
- תכונה: מפגשים החורגים מהמגבלה המותרת לא ניתנים עוד לעריכה או לשמירה כל עוד הרישיון אינו פעיל.
- תכונה: אפשרות חדשה: למרכז את ההנחיה שנמצאת בעריכה.
- תכונה: לחיצה על שם המוזיקה המתנגנת מאתרת את המקור שלה: תרגיל או חיפוש.
- TECH: רישום לוג של תהליך העדכון.
- TECH: שונה אימייל הניהול שנשלח בעת יצירה.
