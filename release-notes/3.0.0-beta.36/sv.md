# Viktigaste ändringarna

- UI: Ljusgloria / blinkning på noterna när musik spelas har lagts till och harmoniserats.
- UI: Fet stil när musik spelas.
- UI: Hjälptexten för sökning har ändrats och beror nu på de verkliga maxgränserna beroende på om licensen är aktiverad eller inte.
- UI: Zoom hanteras vid initiering.
- UI: Zoom vid hovring över övningar, pennikoner och andra kontroller.
- DEBUG: Korrigerad förskjutning av sökresultatet som spelas vid upprepade tryck på Enter.
- FUNKTION: Utan aktiv licens förblir interaktionerna tillgängliga och endast gränsen för antalet musikspår per övning ändras.
- UI: Inget synligt BIOP / BIOPLayer / Bioplayer återstår; endast BIOPlayer visas.
- UI: Inga SMS-liknande emotikoner finns kvar i UI-JSON-filerna.
- UI: Begränsningen för höger-till-vänster-förskjutning i spelad musik har tagits bort.
- FUNKTION: Läget utan aktiv licens begränsar åter sessioner till 5 övningar.
- FUNKTION: Gränsen för antalet musikspår per övning beror nu på licensen.
- FUNKTION: Tillägg, duplicering, import och drops av övningar respekterar nu den licensrelaterade gränsen.
- FUNKTION: Sessioner som överskrider den tillåtna gränsen kan inte längre ändras eller sparas så länge licensen inte är aktiv.
- FUNKTION: Nytt alternativ: centrera instruktionen som redigeras.
- FUNKTION: Ett klick på namnet på musiken som spelas hittar dess ursprung: övning eller sökning.
- TECH: Loggning av uppdateringsproceduren.
- TECH: Admin-e-post vid skapande har ändrats.
