# BIOPlayer 3.1.0
- Κατάλογος IBF 2012: δυνατότητα αναπαραγωγής μουσικής, δημιουργίας ασκήσεων και αντιγραφής κειμένου από τον κατάλογο
- Προστέθηκε προεπιλεγμένος φάκελος για τις συνεδρίες και τη μουσική
- Δυνατότητα αλλαγής ψευδωνύμου
- Το μολύβι παραμένει ορατό ακόμη και όταν ενημερώνεται η συγκεκριμένη άσκηση
- Διόρθωση σφάλματος: μερικές φορές κάποιες ασκήσεις εμφανίζονταν λευκές ενώ δεν αναπαράγονταν ούτε επεξεργάζονταν
- Βελτίωση μεταφράσεων
- Βελτίωση της οπτικής ανατροφοδότησης κατά τη δημιουργία ή ενημέρωση του ευρετηρίου
- Βελτίωση της απόδοσης των μουσικών φασμάτων
- Προστέθηκαν αριθμός τηλεφώνου και κατάσταση καθηγητή/μη καθηγητή κατά τη δημιουργία λογαριασμού
- Ενισχύθηκε η δυνατότητα να υπάρχουν ταυτόχρονα εγκατεστημένες η έκδοση beta και η σταθερή έκδοση
