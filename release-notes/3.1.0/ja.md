# BIOPlayer 3.1.0
- IBF 2012カタログ: 音楽の再生、エクササイズの作成、カタログからのテキストコピーが可能になりました
- セッション用と音楽用の既定フォルダーを追加
- ニックネームを変更できるようにしました
- そのエクササイズを更新中でも鉛筆アイコンが表示されたままになります
- バグ修正: 再生中でも編集中でもないエクササイズが、ときどき白く表示されることがありました
- 翻訳を改善しました
- インデックス作成または更新時の視覚的なフィードバックを改善しました
- 音楽スペクトルの表示を改善しました
- アカウント作成時に電話番号と、教師かどうかのステータスを追加
- ベータ版と安定版を同時にインストールしておける仕組みを強化
