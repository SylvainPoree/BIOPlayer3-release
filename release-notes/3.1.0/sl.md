# BIOPlayer 3.1.0
- Katalog IBF 2012: možnost predvajanja glasbe, ustvarjanja vaj in kopiranja besedila iz kataloga
- Dodana privzeta mapa za seanse in glasbo
- Dodana možnost spreminjanja vzdevka
- Svinčnik ostane viden tudi takrat, ko se posodablja prav ta vaja
- Popravek napake: vaje so se včasih prikazale belo, čeprav se niso niti predvajale niti urejale
- Izboljšave prevodov
- Izboljšan vizualni odziv pri ustvarjanju ali posodabljanju indeksa
- Izboljšano upodabljanje glasbenih spektrov
- Pri ustvarjanju računa sta dodana telefonska številka in status učitelj/ni učitelj
- Okrepljena možnost, da sta hkrati nameščeni beta različica in stabilna različica
