# BIOPlayer 3.1.0
- Каталог IBF 2012: возможность запускать музыку, создавать упражнения и копировать текст из каталога
- Добавлена папка по умолчанию для сеансов и музыки
- Добавлена возможность изменять псевдоним
- Карандаш остается видимым, даже когда обновляется именно это упражнение
- Исправлена ошибка: иногда упражнения отображались белым цветом, хотя они не воспроизводились и не редактировались
- Улучшены переводы
- Улучшена визуальная обратная связь при создании или обновлении индекса
- Улучшено отображение музыкальных спектров
- При создании учетной записи добавлены номер телефона и статус преподаватель/не преподаватель
- Усилена возможность одновременно иметь установленными бета-версию и стабильную версию
