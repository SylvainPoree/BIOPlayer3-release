# BIOPlayer 3.1.0
- IBF 2012 catalogue: play music, create exercises and copy text from the catalogue
- Added a default folder for sessions and music
- Added the ability to edit the nickname
- The pencil stays visible even when that exercise is being updated

- Improved translations
- Improved visual feedback when creating or updating the index
- Improved rendering of music spectra
- Added phone number and teacher/non-teacher status when creating an account
- Strengthened the ability to keep both the beta version and the stable version installed
