# BIOPlayer 3.1.1-beta.3

- 音楽の命名設定を追加しました。表示する項目（タイトル、アーティスト、アルバム、ファイル名、拡張子）を選択し、順序をカスタマイズできます。
- PDF 内の音楽用に、独立した命名設定を追加しました。
- 検索条件にアルバムを追加しました。
- 別の場所で音楽を分割または削除したとき、またはエクササイズを削除したときに、現在のエクササイズまで意図せずスクロールする問題を修正しました。
- BIOPlayer の起動で、シングルクリックではなくダブルクリックが必要になることがある問題を修正しました。
- セッションの読み込み時に不足している音楽が 3 曲を超える場合、セッション全体の不足音楽を検索できるようになりました。
