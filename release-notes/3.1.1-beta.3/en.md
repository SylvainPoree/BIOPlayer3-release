# BIOPlayer 3.1.1-beta.3

- Added a music naming setting: choose which fields to display (title, artist, album, file name, extension) and customize their order.
- Added an independent naming setting for music in PDFs.
- Added the Album criterion to the search criteria.
- Fixed unwanted scrolling to the current exercise when music is cut or deleted elsewhere, or when an exercise is deleted.
- Fixed BIOPlayer startup, which sometimes required a double-click instead of a single click.
- Ability to search for missing music across an entire session when more than three tracks are missing while loading the session.
