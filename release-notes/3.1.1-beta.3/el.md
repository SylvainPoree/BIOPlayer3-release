# BIOPlayer 3.1.1-beta.3

- Προστέθηκε ρύθμιση ονομασίας μουσικής: επιλογή των πεδίων που θα εμφανίζονται (τίτλος, καλλιτέχνης, άλμπουμ, όνομα αρχείου, επέκταση) και προσαρμόσιμη σειρά.
- Προστέθηκε ανεξάρτητη ρύθμιση ονομασίας για τις μουσικές στα PDF.
- Προστέθηκε το κριτήριο Άλμπουμ στα κριτήρια αναζήτησης.
- Διορθώθηκε η απρόσμενη κύλιση προς την τρέχουσα άσκηση όταν κόβεται ή διαγράφεται μουσική αλλού, ή όταν διαγράφεται μια άσκηση.
- Διορθώθηκε η εκκίνηση του BIOPlayer, η οποία μερικές φορές απαιτούσε διπλό κλικ αντί για απλό κλικ.
- Δυνατότητα αναζήτησης της μουσικής που λείπει για ολόκληρη τη συνεδρία όταν λείπουν περισσότερα από τρία μουσικά κομμάτια κατά τη φόρτωση της συνεδρίας.
