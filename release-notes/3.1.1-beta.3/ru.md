# BIOPlayer 3.1.1-beta.3

- Добавлена настройка именования музыки: выбор отображаемых полей (название, исполнитель, альбом, имя файла, расширение) и настраиваемый порядок.
- Добавлена отдельная настройка именования музыки в PDF.
- В критерии поиска добавлен критерий Альбом.
- Исправлена нежелательная прокрутка к текущему упражнению при разрезании или удалении музыки в другом месте, а также при удалении упражнения.
- Исправлен запуск BIOPlayer, для которого иногда требовался двойной щелчок вместо одиночного.
- Возможность искать отсутствующую музыку для всего занятия, если при загрузке занятия отсутствует более трех музыкальных файлов.
