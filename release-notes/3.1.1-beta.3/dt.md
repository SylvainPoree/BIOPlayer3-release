# BIOPlayer 3.1.1-beta.3

- Einstellung für die Benennung von Musik hinzugefügt: Auswahl der anzuzeigenden Felder (Titel, Künstler, Album, Dateiname, Erweiterung) und anpassbare Reihenfolge.
- Separate Einstellung für die Benennung von Musik in PDFs hinzugefügt.
- Das Suchkriterium Album wurde hinzugefügt.
- Unerwartetes Scrollen zur aktuellen Übung wurde behoben, wenn Musik an anderer Stelle geschnitten oder gelöscht wird oder wenn eine Übung gelöscht wird.
- Der Start von BIOPlayer wurde korrigiert, der manchmal einen Doppelklick statt eines einfachen Klicks erforderte.
- Möglichkeit, fehlende Musik für eine ganze Sitzung zu suchen, wenn beim Laden der Sitzung mehr als drei Musikstücke fehlen.
