# BIOPlayer 3.1.4-beta.2

- Visualisation instantanée du spectre, de gauche à droite.
- Possibilité de croiser les poignées de découpage pour supprimer une partie centrale d'un morceau.
- Possibilité d'activer la synchronisation rythmique automatique lors d'une coupe sèche, d'une boucle ou d'enchaînements sur un même morceau.
- Révision des libellés des options.
- Révision de la présentation des options.
- Utilisation de Ctrl + roulette de la souris pour augmenter ou réduire le zoom global.
- Diverses améliorations de la courbe physiologique.
- Le bouton « Activer ma licence » vérifie d'abord si la licence est déjà activée.
- Sur Mac, le bouton de téléchargement d'une mise à jour s'affiche seulement lorsqu'une nouvelle version est disponible.
- Améliorations du menu contextuel des exercices.
- Les suggestions de remplacement de fichier excluent les fichiers déjà présélectionnés dans l'exercice.
- Possibilité d'inclure la courbe physiologique dans les PDF.
- Migration du code vers TypeScript.
