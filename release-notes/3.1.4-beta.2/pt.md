# BIOPlayer 3.1.4-beta.2

- Visualização instantânea do espectro, da esquerda para a direita.
- As alças de recorte podem se cruzar para remover uma seção central de uma faixa.
- Possibilidade de ativar a sincronização rítmica automática em cortes secos, repetições em loop ou transições dentro da mesma faixa.
- Revisão dos rótulos das opções.
- Revisão da apresentação das opções.
- Uso de Ctrl + roda do mouse para aumentar ou reduzir o zoom global.
- Diversas melhorias na curva fisiológica.
- O botão «Ativar minha licença» verifica primeiro se a licença já está ativada.
- No Mac, o botão para baixar uma atualização só aparece quando há uma nova versão disponível.
- Melhorias no menu de contexto dos exercícios.
- As sugestões de substituição de arquivos excluem os arquivos já pré-selecionados no exercício.
- Possibilidade de incluir a curva fisiológica nos PDFs.
- Migração do código para TypeScript.
