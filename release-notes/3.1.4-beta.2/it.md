# BIOPlayer 3.1.4-beta.2

- Visualizzazione istantanea dello spettro, da sinistra a destra.
- Le maniglie di ritaglio possono incrociarsi per eliminare una sezione centrale di un brano.
- Possibilità di attivare la sincronizzazione ritmica automatica per tagli netti, ripetizioni in loop o transizioni all'interno dello stesso brano.
- Revisione delle etichette delle opzioni.
- Revisione della presentazione delle opzioni.
- Uso di Ctrl + rotellina del mouse per aumentare o ridurre lo zoom globale.
- Vari miglioramenti della curva fisiologica.
- Il pulsante «Attiva la mia licenza» verifica prima se la licenza è già attivata.
- Su Mac, il pulsante per scaricare un aggiornamento appare solo quando è disponibile una nuova versione.
- Miglioramenti del menu contestuale degli esercizi.
- I suggerimenti per la sostituzione dei file escludono i file già preselezionati nell'esercizio.
- Possibilità di includere la curva fisiologica nei PDF.
- Migrazione del codice a TypeScript.
