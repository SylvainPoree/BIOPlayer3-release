# BIOPlayer 3.1.4-beta.2

- Instant spectrum display, from left to right.
- Trimming handles can cross, allowing you to remove a middle section of a track.
- Automatic rhythm synchronization can be enabled for hard cuts, loops or transitions within the same track.
- Revised option labels.
- Revised layout of the options.
- Use Ctrl + mouse wheel to zoom the entire interface in or out.
- Various improvements to the physiological curve.
- The “Activate my licence” button first checks whether the licence is already activated.
- On Mac, the update download button only appears when a new version is available.
- Improvements to the exercise context menu.
- File replacement suggestions exclude files already preselected in the exercise.
- The physiological curve can now be included in PDFs.
- Code migrated to TypeScript.
