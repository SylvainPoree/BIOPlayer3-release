# BIOPlayer 3.1.4-beta.2

- スペクトルを左から右へ即座に表示。
- トリミングハンドルを交差させて、曲の中央部分を削除できるようになりました。
- 同じ曲内でのハードカット、ループ、つなぎに対して、自動リズム同期を有効にできるようになりました。
- オプションのラベルを見直しました。
- オプションの表示を見直しました。
- Ctrl + マウスホイールで、インターフェース全体を拡大・縮小できます。
- 生理曲線に関するさまざまな改善。
- 「ライセンスを有効化」ボタンは、ライセンスがすでに有効化されているかを最初に確認します。
- Macでは、新しいバージョンが利用可能な場合にのみ、更新のダウンロードボタンを表示します。
- エクササイズのコンテキストメニューを改善しました。
- ファイルの置き換え候補から、そのエクササイズですでに事前選択されているファイルを除外します。
- PDFに生理曲線を含められるようになりました。
- コードをTypeScriptに移行しました。
