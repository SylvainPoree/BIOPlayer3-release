# Κύριες αλλαγές

- UI: Η φούσκα εξαφανίζεται πιο γρήγορα κατά τη μετάβαση από την αναζήτηση στη συνεδρία.
- UI: Εικονίδιο εφαρμογής στο Linux.
- UI: Κείμενο πριν από την εισαγωγή σε γκρι: "Η άσκησή μου" και "Η συνεδρία μου".
- UI: Πιο λεπτομερής διαχείριση της αιώρησης πάνω από τις μουσικές της συνεδρίας.
- ΛΕΙΤΟΥΡΓΙΑ: Άγνωστο αρχείο μουσικής: προστίθενται ισοδύναμες μουσικές στην άσκηση όταν δεν βρεθεί αρχείο με το ίδιο όνομα.
