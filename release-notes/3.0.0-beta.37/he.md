# שינויים עיקריים

- UI: הבועה נעלמת מהר יותר במעבר מהחיפוש אל הסשן.
- UI: אייקון היישום בלינוקס.
- UI: טקסט לפני הוספה מוצג באפור: "התרגיל שלי" ו"הסשן שלי".
- UI: ניהול מדויק יותר של ריחוף מעל קטעי המוזיקה בסשן.
- תכונה: קובץ מוזיקה לא מוכר: קטעי מוזיקה שקולים נוספים לתרגיל כאשר לא נמצא קובץ עם אותו שם.
