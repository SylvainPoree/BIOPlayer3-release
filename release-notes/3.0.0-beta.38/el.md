# Κύριες αλλαγές

- DEBUG: Σταθεροποίηση της άσκησης που βρίσκεται υπό επεξεργασία κατά την προσθήκη ή διαγραφή άσκησης.
- DEBUG: Εκκίνηση στο Debian χωρίς πλέον να ζητείται η ενημέρωση.
- DEBUG: Ενίσχυση της αποθήκευσης των επιλογών: το μέγιστο όριο αναζήτησης δεν λειτουργούσε.
- UI: Διεύρυνση της περιοχής μηνυμάτων πριν από τις αναζητήσεις.
- UI: Προσθήκη νότας στον δίσκο για τις μουσικές που αναπαράγονται.
- UI: Μετακίνηση του σύμπτυξη/ανάπτυξη κοντά στο κουμπί Προσθήκη άσκησης.
- ΛΕΙΤΟΥΡΓΙΑ: Μενού περιβάλλοντος για αλλαγή ροών.
- TECH: Εργασία στον διαχωρισμό των εκδόσεων Dev, Beta και Pro και στις αυτόματες ενημερώσεις.
