# BIOPlayer 3.1.3

- Improved physiological curve visualization.
- Interactive physiological curve:
    - Create and move exercises.
    - Create and move peaks.
    - Rename exercises.
    - Play music.
- In searches, quotation marks let you search for an exact phrase, including spaces.
- In searches, `!` excludes a term: if you don't like Zamfir, `breathing ! zamfir` finds breathing music without Zamfir.
- Various display improvements.
