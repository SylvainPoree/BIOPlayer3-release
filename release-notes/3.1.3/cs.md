# BIOPlayer 3.1.3

- Vylepšení zobrazení fyziologické křivky.
- Interaktivita fyziologické křivky:
    - Vytváření a přesouvání cvičení.
    - Vytváření a přesouvání vrcholů.
    - Přejmenování cvičení.
    - Přehrávání hudby.
- Při vyhledávání umožňují uvozovky hledat přesnou frázi včetně mezer.
- Při vyhledávání umožňuje `!` vyloučit výraz: pokud nemáš rád Zamfira, `dýchání ! zamfir` najde hudbu pro dýchání bez Zamfira.
- Různá vylepšení zobrazení.
