# BIOPlayer 3.1.3

- Ulepszono wizualizację krzywej fizjologicznej.
- Interaktywność krzywej fizjologicznej:
    - Tworzenie i przesuwanie ćwiczeń.
    - Tworzenie i przesuwanie szczytów.
    - Zmiana nazw ćwiczeń.
    - Odtwarzanie muzyki.
- Podczas wyszukiwania cudzysłów pozwala szukać dokładnej frazy, łącznie ze spacjami.
- Podczas wyszukiwania `!` pozwala wykluczyć wyrażenie: jeśli nie lubisz Zamfira, `oddychanie ! zamfir` znajdzie muzykę do oddychania bez Zamfira.
- Różne ulepszenia wyświetlania.
