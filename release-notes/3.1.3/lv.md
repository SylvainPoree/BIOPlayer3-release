# BIOPlayer 3.1.3

- Uzlabota fizioloģiskās līknes vizualizācija.
- Fizioloģiskās līknes interaktivitāte:
    - Vingrinājumu izveide un pārvietošana.
    - Maksimumu izveide un pārvietošana.
    - Vingrinājumu pārdēvēšana.
    - Mūzikas atskaņošana.
- Meklēšanā pēdiņas ļauj meklēt precīzu frāzi, ieskaitot atstarpes.
- Meklēšanā `!` ļauj izslēgt vārdu: ja tev nepatīk Zamfir, `elpošana ! zamfir` atrod elpošanas mūziku bez Zamfir.
- Dažādi attēlojuma uzlabojumi.
