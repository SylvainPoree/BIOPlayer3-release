# BIOPlayer 3.1.3

- Улучшена визуализация физиологической кривой.
- Интерактивная физиологическая кривая:
    - Создание и перемещение упражнений.
    - Создание и перемещение пиков.
    - Переименование упражнений.
    - Воспроизведение музыки.
- При поиске кавычки позволяют искать точную фразу с учётом пробелов.
- При поиске `!` позволяет исключить слово: если тебе не нравится Zamfir, поиск `дыхание ! zamfir` найдёт музыку для дыхания без Zamfir.
- Различные улучшения отображения.
