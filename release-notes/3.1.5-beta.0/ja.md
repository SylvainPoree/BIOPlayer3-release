# BIOPlayer 3.1.5-beta.0

- 生理曲線の印刷やPDF形式でのエクスポートが可能に（Laurent P.さんに感謝）。
- エクササイズの展開・折りたたみに3つのモードを用意。新モード「選択した音楽を含むもの＋同じ音楽を含むもの」を追加（Zoë R.さんに感謝）。
- 有効なライセンスがなくても、指示の内容やエクササイズ名を編集可能に（Pegyy S.さんに感謝）。
- iTunesライブラリ全体のインポートに対応。
- アニメーション付きの紹介を追加。最初のステップは新規ユーザーに表示。
- BIOPlayerの機能を知るためのツアーを追加。
- 中央エリアに限り、ピークに関するメニュー項目を削除。
- 不具合の修正：
    - まれな特定のつなぎ方で、現在のエクササイズではなく次のエクササイズの音楽が始まる問題を修正。
    - エクササイズの複製や外部からのコピーで、活性化ピークが保持されない問題を修正。
- 左上のメニューを開いている間は、検索エリアの音楽情報バブルを無効化。
- Linuxでのインストール後の再起動メッセージを変更。
- Windowsの自動更新では、新バージョンをサイレントモードでインストールし、セッションの保存後にBIOPlayerを自動的に再起動。
- 音楽をFLAC形式でエクスポート。 !V4!
- 重複の検索。 !V4!
- ユーザーインターフェースをいくつか改善。
