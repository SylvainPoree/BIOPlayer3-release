# BIOPlayer 3.1.5-beta.0

- Kurba fisiologikoa inprimatzeko edo PDF formatuan esportatzeko aukera (eskerrik asko Laurent P.ri).
- Ariketak zabaltzeko edo tolesteko hiru modu, «hautatutako musikarekin + musika berberekin» modu berria barne (eskerrik asko Zoë R.ri).
- Jarraibideen edukia eta ariketen izenak aldatzeko aukera, lizentzia aktiborik gabe ere (eskerrik asko Pegyy S.ri).
- iTunes liburutegi oso bat inportatzeko aukera.
- Aurkezpen animatu bat gehitu da; lehen urratsa erabiltzaile berriei erakusten zaie.
- BIOPlayerren funtzioak ezagutzeko ibilbide bat gehitu da.
- Gailurrei buruzko menu-elementuak kendu dira, erdiko eremuan soilik.
- Akatsen zuzenketak:
    - Trantsizio-kasu bakan batzuetan, hurrengo ariketaren musika abiarazten zen uneko ariketarenaren ordez.
    - Ariketa bat bikoiztean edo kanpotik kopiatzean, aktibazio-gailurra ez zen mantentzen.
- Bilaketa-eremuko musikari buruzko informazio-burbuilak desaktibatzen dira goiko ezkerreko menua irekita dagoen bitartean.
- Linuxen instalazioaren ondoren berrabiarazteko mezua aldatu da.
- Windowsen, eguneratze automatikoak bertsio berria modu isilean instalatzen du orain, eta BIOPlayer automatikoki berrabiarazten du saioak gorde ondoren.
- Musika FLAC formatuan esportatzea. !V4!
- Bikoiztuak bilatzea. !V4!
- Erabiltzaile-interfazearen hainbat hobekuntza.
